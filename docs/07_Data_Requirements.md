## 1. Data sources overview

| Source | File | Grain | Rows (approx.) | Update frequency | Owner |
|---|---|---|---|---|---|
| Sales (train) | `train.csv` | store × family × day | 3,000,888 | Daily (historical) | POS / ERP |
| Sales (test) | `test.csv` | store × family × day | 28,512 | Future horizon | POS / ERP |
| Store master | `stores.csv` | store | 54 | Rarely | Master data |
| Oil price | `oil.csv` | day | ~1,200 | Daily | External (EIA/WTI) |
| Holidays | `holidays_events.csv` | event | 350 | Annually | HR / Government |
| Transactions | `transactions.csv` | store × day | ~834K | Daily | POS |

**Period:** Training 2013-01-01 → 2017-08-15; Forecast horizon 2017-08-16 → 2017-08-31 (16 days)

## 4. Data quality requirements

| Rule ID | Requirement | Threshold | Action if violated |
|---|---|---|---|
| DQ-01 | No duplicate `id` in train | 0 duplicates | Stop pipeline |
| DQ-02 | Merged row count equals train row count | 3,000,888 | Investigate join logic |
| DQ-03 | All stores in train exist in stores.csv | 100% match | Flag orphan stores |
| DQ-04 | Date range continuous in train | 2013-01-01 → 2017-08-15 | Document gaps |
| DQ-05 | Sales ≥ 0 | No negatives | Flag / investigate |
| DQ-06 | Missing oil price after fill | 0 | Re-run fill logic |
| DQ-07 | Holiday dedup before merge | 1 row per date (national) | Deduplicate |
